\# 🚀 LabSimulator - Wirtualne Laboratorium Automatyki

!\[Qt](https://img.shields.io/badge/Qt-6.8-green.svg)

!\[Status](https://img.shields.io/badge/Status-In%20Development-yellow.svg)



Symulacyjne środowisko wirtualnych stanowisk laboratoryjnych dla automatyki (sterowanie analogowe).



\## 🛠 Kluczowe Funkcjonalności

\* \*\*Symulacja obiektów:\*\* Silniki DC, transmitancje rzędu 2 i 3.

\* \*\*Algorytmy:\*\* PID z anti-windup, LQR, przekaźniki z histerezą.

\* \*\*UI/UX:\*\* Interaktywne okablowanie, wirtualny oscyloskop dwukanałowy.

\* \*\*Eksport danych:\*\* Automatyczny zapis przebiegów do plików `.csv`.



\## 📂 Struktura Projektu

\* `src/` - Implementacja logiki i GUI.

\* `include/` - Pliki nagłówkowe.

\* `ui/` - Pliki interfejsu Qt Designer.

\* `data/` - Wyniki symulacji (CSV) dla poszczególnych zadań.



\## 🚀 Uruchomienie

1\. Otwórz projekt w \*\*Qt Creator\*\*.

2\. Wybierz Kit \*\*Desktop Qt 6.8.3 MSVC2022 64bit\*\*.

3\. Skompiluj i uruchom (Ctrl+R).
